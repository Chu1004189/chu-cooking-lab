# CHU dot COOKING LAB

レシピを研究・管理するためのスタンドアロン版プロトタイプです。

## ファイル
- `index.html` — トップ / 編集画面
- `style.css` — デザイン
- `app.js` — 保存・編集・並び替え・画像・パーツ・材料リンク・コード生成

## 現在できること
- レシピ一覧
- 「研究中 / 完成済」フィルター
- 新規レシピ作成
- ID / タイトル編集
- iPhoneの写真から画像追加
- 複数タグ
- 1〜5人前 / 選択なし
- 材料の追加・削除・ドラッグ並び替え
- サンプルのレシピパーツ選択
- 手順追加・削除
- 手順と材料の紐付け
- searchText自動生成
- localStorageへの自動保存
- recipes.js形式のコード生成
- コードコピー

## 保存について
現段階ではブラウザのlocalStorageに保存します。
そのため、同じブラウザ・同じ端末で使う前提です。

## 画像について
画像はブラウザ内にデータとして保存するプロトタイプです。
GitHub Pagesへ公開する際には、画像をGitHubの`images`フォルダへアップロードしてURL化する仕組みに変更するのが次の段階です。

## パーツについて
現在は動作確認用のサンプルパーツを `app.js` の `PARTS` に入れています。
後で実際のCHU dot COOKINGのパーツ管理データに合わせて差し替えられます。
